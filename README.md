# 一番くじウィジェット

一番くじの販売予定を月ごとに確認できる、ブラウザー向けの小さなアプリです。店頭・オンラインの販売日や取扱店舗を確認したり、気になるくじを「買いたい！」として一覧の上部にまとめたりできます。

## 主な機能

- 年・月を選んで販売予定を表示
- オンライン販売があるくじに絞り込み
- 商品画像・販売情報・公式リンクをカード形式で表示し、画像がない商品はプレースホルダーを表示
- 商品カードの☆でお気に入り登録し、登録商品を一覧の上部に表示
- タイトルを登録してお気に入り表示・通知
- 「買いたい！」にチェックしたくじを一覧の上部に表示
- 公式マイページからダブルチャンス挑戦回数を取り込み
- 商品ページ、公式店舗検索、オンライン販売ページへのリンク
- チェックやお気に入り、表示期間をブラウザーに保存

## 動作要件

- Python 3.10 以上
- Microsoft Edge
- `requirements.txt` に記載した Python パッケージ
- 一番くじ情報を取得する場合はインターネット接続

## 起動方法

リポジトリのルートディレクトリで、初回のみ依存パッケージをインストールします。

```bash
python -m pip install -r requirements.txt
```

サーバーを起動します。

```bash
python server.py
```

Windows で `python` コマンドが使えない場合は、代わりに次を実行してください。

```powershell
py -3 server.py
```

Windows では `start_localhost.cmd` からも起動できます。ブラウザーで <http://localhost:8000> を開きます。ターミナルから起動した場合は、終了するときに `Ctrl+C` を押してください。

別のポートを使う場合は、`PORT` 環境変数を設定してから起動します。例：

```powershell
$env:PORT = "8080"
python server.py
```

## 使い方

1. オプション（右上の「⋯」）から表示する年・月を選びます。
2. 「全件」または「オンライン販売あり」で一覧を切り替えます。
3. 商品カードの☆でお気に入り登録、またはカード上部の「買いたい！」にチェックします。お気に入りとチェックしたくじは一覧の上部に移動します。
4. 好きな作品名をオプションの「好きなタイトル」に登録すると、一致するくじが強調表示されます。
5. 「最新を取得」を押すと、選択中の月の情報を一番くじ公式サイトから取得し、`data/lotteries.json` に保存します。
6. ダブルチャンス挑戦回数は、オプションの「ログインして回数を取得」を押します。初回は専用のEdgeが開くので公式マイページにログインしてください。ログイン後は自動で回数を取得します。次回からはボタンを押すだけです。

タイトルや表示期間、チェック状態、取り込んだ挑戦回数はブラウザーごとに保存されます。別のブラウザーや端末とは共有されません。アプリはID・パスワードを取得・保存しません。ログイン状態は `.local/mypage-browser/` に端末内だけで保存され、Git管理対象外です。ログイン状態が切れた場合は、専用Edgeで再ログインしてください。

サーバーはこのPC内（`127.0.0.1`）だけで待ち受けるため、同じネットワーク上の別端末からは利用できません。

## データについて

`data/lotteries.json` は、取得した情報を保存する JSON ファイルです。手動で編集する場合は、トップレベルに `lotteries` 配列を用意します。日付は `YYYY-MM-DD` 形式です。

```json
{
  "lotteries": [
    {
      "title": "一番くじ 作品名",
      "category": "一番くじ",
      "prize": "最新情報",
      "date": "2026-11-05",
      "online_date": "2026-11-05",
      "online_time": "17:00",
      "stores": ["ローソン", "書店"],
      "note": "販売に関するメモ",
      "url": "https://1kuji.com/products/example",
      "thumbnail": "",
      "online_url": "https://on-line.1kuji.com/"
    }
  ]
}
```

「最新を取得」を実行すると、このファイルは取得結果で更新されます。取得データは環境ごとに異なるため、`data/lotteries.json` は Git 管理対象外です。初回取得時にファイルが作成されます。

## 公開・ホスティングについて

このアプリは Python サーバーが情報取得 API を提供します。そのため、HTML/CSS/JavaScript のファイルだけを配信する GitHub Pages などの静的ホスティングでは、一覧の情報取得機能は動作しません。公開して利用するには、`server.py` を実行できるホスティング環境が必要です。
